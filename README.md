# RPG de Batalha

Jogo de batalha por turnos em Java, desenvolvido como projeto final da disciplina de Programação Orientada a Objetos.



## Sobre o jogo

A batalhas acontece por turnos entre dois jogadores, onde cada um inicia com 100 HP e 0 de energia. Para batalhar, cada jogador conta com três opções de ação:

- Ataque: causa 15 de dano no alvo e dá 25 de energia para o autor

- Defesa: reduz 50% do próximo dano que o alvo irá receber e dá 15 de energia para o autor

- Especial: causa 30 de dano, exigindo 100 de energia

&#x20; 

Vence aquele que conseguir zerar o HP do adversário primeiro
